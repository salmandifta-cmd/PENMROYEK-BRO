Panduan Import File Jadwal MS Project (.MPP) & Excel
Cara tercepat mengunggah jadwal proyek ke sistem PENMROYEK
Sistem PENMROYEK mendukung penuh file .XML (Format Standar MS Project), .XLSX (Microsoft Excel), dan .CSV. Untuk file biner .MPP, sistem akan mengekstrak nama pekerjaan secara otomatis atau Anda dapat menyimpannya ke format XML / Excel dalam 2 klik di Microsoft Project untuk hasil 100% presisi.
Metode 1: Simpan sebagai XML di MS Project
  1. Buka file proyek Anda di Microsoft Project.
  2. Klik menu File → Save As (Simpan Sebagai).
  3. Pada pilihan Save as type, pilih:
    XML Format (*.xml).
  4. Klik Save, lalu upload file .xml tersebut ke PENMROYEK.
100% Akurat dengan Tanggal & Durasi Asli
